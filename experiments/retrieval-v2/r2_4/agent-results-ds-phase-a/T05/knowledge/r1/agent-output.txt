## What the document describes

Its heading path — "当后端server可以挂在一个命名服务内时 / Backup Request 限流 / 使用内置限流策略" (EN: "When backend servers can be hung in a naming service / Rate-limited backup requests / Using the built-in rate-limiting policy") — defines the scope: when the client's backends sit behind a naming service, a backup ("hedged") request is fired if the primary RPC exceeds `backup_request_ms`, and the module caps the backup fraction so it doesn't amplify load during latency spikes.
