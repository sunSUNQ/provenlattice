## `aria2.DownloadEngine`

- **File:** `src/DownloadEngine.h`
- **Declaration line:** 84 (the class body spans lines 84–335)

**Responsibility:** `DownloadEngine` is aria2's central event loop / command scheduler. Its `run()` method drives repeated polling of the `EventPoll` object and dispatches queued `Command` objects (routine and one-shot), which is how all downloads and services make progress (src/DownloadEngine.h:183; src/DownloadEngine.cc:158). It also owns the shared per-run state that commands reach through it: the `RequestGroupMan`, `FileAllocationMan`, `CheckIntegrityMan`, DNS cache, cookie storage, a pooled-socket cache, statistics, and halt-request flags.
