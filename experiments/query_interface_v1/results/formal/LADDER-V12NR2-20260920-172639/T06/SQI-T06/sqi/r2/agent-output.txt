**Verified claim (read from source)**
`IsAskedToQuit()` reports whether a process-quit signal has been received. `controller.cpp:1976-1979` first runs `pthread_once(&register_quit_signal_once, RegisterQuitSignalOrDie)` to install the handlers, then returns the file-static `volatile bool s_signal_quit` (`controller.cpp:1922`). That flag is set to `true` by `quit_handler(int)` (`controller.cpp:1927-1928`), which is registered for SIGINT (line 1944), SIGTERM (1954), and SIGHUP (1965). So the function returns `true` once SIGINT/SIGTERM/SIGHUP has fired — the idiomatic "should I stop my loop" check used by the example client loops above (`AskToQuit()` at line 1981 just `raise(SIGINT)`).
