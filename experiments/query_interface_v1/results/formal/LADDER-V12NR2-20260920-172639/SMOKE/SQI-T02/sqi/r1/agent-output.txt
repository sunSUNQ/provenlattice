## What it returns (verified by reading the definition)

From `src/butil/status.h:99-101`:

```cpp
const char* error_cstr() const {
    return (_state == nullptr ? "OK" : _state->message);
}
```

It returns a `const char*`:
- `"OK"` when the status is a success (`_state == nullptr`, i.e. `ok()` is true);
- otherwise `_state->message`, the NUL-terminated raw error-message buffer of the failed `State` (see the `State::message[0]` definition at `status.h:48`).

The header itself warns (`status.h:96-98`) that if the message contains an embedded `'\0'`, `error_cstr()` will not be shown fully — because it stops at the first NUL, unlike the sibling `error_data()` which carries an explicit size.
