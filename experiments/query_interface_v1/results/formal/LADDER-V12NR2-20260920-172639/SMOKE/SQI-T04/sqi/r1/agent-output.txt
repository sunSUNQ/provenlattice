## What the frontier does and does not tell you

**Tells you:** the exact set of shards holding a structural compile/link dependency on the changed `db`/`file` shards, the direction (dependent-side), the per-shard boundary-edge count (an exact aggregate), and that the blast radius is repo-wide rather than local.

**Does not tell you:** (1) any symbol-level impact — `result_meta.note` states "no symbol-level impact is derivable from this call"; (2) *which* symbol changed or whether a given dependent's call sites break — a shard can depend on `file` via a different header symbol than the one edited; (3) transitive (2-hop+) propagation — this is strictly 1-hop; (4) runtime/behavioral impact or severity — every edge is confidence 1.0 structural dependency only, no risk weighting; (5) the omitted 981 boundary edges (only a 50-id prefix was returned). Membership is a compile-dependency fact, not evidence that code must be edited.
