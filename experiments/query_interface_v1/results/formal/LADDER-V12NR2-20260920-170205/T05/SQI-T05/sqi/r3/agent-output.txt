**Documented behavior.** `docs/cn/client.md`, section **负载均衡 / c_murmurhash_bl** (lines 286–289), describes *Consistent Hashing with Bounded Loads* (Mirrokni et al., CACM 2017): the hash ring is identical to `c_murmurhash`, but each server has a capacity `ceil(load_factor * 平均在途请求数)`; when the hashed-to server is at capacity the request overflows clockwise to the next server with spare capacity. `load_factor` defaults from `-chash_bounded_load_factor` (1.25, must be > 1) and is overridable per channel as `c_murmurhash_bl:load_factor=1.5`; `replicas` behaves as in `c_murmurhash`.
