### Verified functional claim
Reading `src/brpc/controller.cpp:1976–1979` confirms the body is `pthread_once(&register_quit_signal_once, RegisterQuitSignalOrDie); return s_signal_quit;`. So `IsAskedToQuit()` (a) installs the quit-signal handlers exactly once via `RegisterQuitSignalOrDie` (`controller.cpp:1942`, registering `quit_handler` for SIGINT, and for SIGTERM/SIGHUP when `FLAGS_graceful_quit_on_sigterm` / `FLAGS_graceful_quit_on_sighup` are set) and (b) returns the process-global `volatile bool s_signal_quit` (`controller.cpp:1922`), which `quit_handler` sets to `true` on receipt of one of those signals (`controller.cpp:1927–1938`). The function is therefore a poll of whether a graceful-quit signal has been received — not a pure type predicate, and it has the side effect of one-time signal-handler registration.
