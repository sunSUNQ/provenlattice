## Verified claim about what the function does

Read of `src/brpc/controller.cpp` confirms the semantics: `IsAskedToQuit()` calls `pthread_once(&register_quit_signal_once, RegisterQuitSignalOrDie)` (controller.cpp:1977), which installs `quit_handler` on SIGINT (line 1944), SIGTERM (1954) and SIGHUP (1965); `quit_handler` sets the file-static `volatile bool s_signal_quit = true` (lines 1922, 1927–1928). The function then returns that flag (line 1978). **So `IsAskedToQuit()` lazily installs the termination-signal handlers once, then reports whether the process has already received a quit signal (SIGINT/SIGTERM/SIGHUP) — it is a "has a shutdown signal been delivered?" check, not a request to quit.** (`AskToQuit()` at line 1981 is the counterpart that raises SIGINT.)
