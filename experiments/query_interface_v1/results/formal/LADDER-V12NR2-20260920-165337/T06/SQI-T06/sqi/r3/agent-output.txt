**Verified claim about what the function does** (read from source, not just the envelope)
`IsAskedToQuit()` takes no arguments; it lazily performs one-time registration of the quit-signal handling via `pthread_once(&register_quit_signal_once, RegisterQuitSignalOrDie)` and then returns the current value of the static `volatile bool s_signal_quit` (`src/brpc/controller.cpp:1976-1979`). `RegisterQuitSignalOrDie` installs `quit_handler` for SIGINT, SIGTERM, and SIGHUP (`controller.cpp:1942-1965`), and `quit_handler` sets `s_signal_quit = true` when any of those signals arrives (`controller.cpp:1922-1938`). So the function is a non-blocking poll reporting whether a quit signal has been received — confirmed by caller usage `while (!brpc::IsAskedToQuit())` at `example/echo_c++/client.cpp:61`.
