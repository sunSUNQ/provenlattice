### Verified claim about what the function does
Reading src/brpc/controller.cpp:1976–1979 confirms the body:

```cpp
bool IsAskedToQuit() {
    pthread_once(&register_quit_signal_once, RegisterQuitSignalOrDie);
    return s_signal_quit;
}
```

It lazily installs the quit-signal handlers exactly once (via `pthread_once` → `RegisterQuitSignalOrDie`, which registers `quit_handler` for SIGINT, and for SIGTERM/SIGHUP under `FLAGS_graceful_quit_on_sigterm`/`FLAGS_graceful_quit_on_sighup`), then returns the process-global `s_signal_quit` flag that `quit_handler` sets to `true` on a quit signal (controller.cpp:1927–1938). So it is a **poll: "has a graceful-quit signal been received?"** — not a blocking wait, and it has the side effect of installing the handlers on first call.
