**Responsibility**

`aria2.DownloadEngine` is aria2's central event-loop driver: its `run()` method polls the event poller (`EventPoll`) and dispatches work by executing the pending commands held in its `commands_` / `routineCommands_` queues. It owns and coordinates the major long-lived managers — `RequestGroupMan`, `FileAllocationMan`, `CheckIntegrityMan`, cookie storage, DNS cache, and the BitTorrent registry — and exposes the socket read/write and name-resolver registration plus the socket-pool API used by commands. It also carries halt/force-halt state, the session id, and token validation for the RPC layer.
