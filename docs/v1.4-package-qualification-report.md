## 4. Known limitations

1. **单平台构建验证**:wheel 为 `py3-none-any`(纯 Python,平台无关),但构建与安装验证仅在 Windows/Python 3.12.10 完成;Linux 安装路径待 P1 CI Linux job 远程 Run 后闭环。
2. **子集而非全量**:venv 内运行 30/412 测试子集;全量 412 已在源码环境验证(P1 报告)。
3. **sdist→构建路径未单独验证**:直接安装 wheel;sdist 的"从源码分发包重建"路径未独立执行(两者出自同一 `python -m build` 运行)。
4. **产物不入库**:`dist/` 未提交 git(哈希以本报告为准,产物仅本地存在),无 publish / tag。
5. venv 依赖安装使用 PyPI 网络(与 CI runner 行为一致)。
