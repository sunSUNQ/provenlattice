### 审查中发现的缺陷(已修复)

`Verify package-data` 步骤原断言 `len(tomls) >= 4`,而 `src/provenlattice/semantics/` 实际仅含 **3 个** TOML(`defect_patterns.toml`、`taint.toml`、`vocabularies/cpp.toml`),与 errata 提交 `c44b77b`(python.toml 未移植,词表范围仅 cpp.toml)一致。该步骤此前从未被执行(仓库无任何 Actions Run),首次真实运行必失败。已修正为精确期望文件集断言(两 job 同步):

```python
expected = {"defect_patterns.toml", "taint.toml", "cpp.toml"}
assert expected <= names
```
