# ProvenLattice 1.5.0 Release Notes — Java Public Beta

> 发布：2026-10-19 · Tag：[`provenlattice-v1.5.0`](https://github.com/sunSUNQ/provenlattice/releases/tag/provenlattice-v1.5.0)
> （指向 main commit `0ec6364`）· 状态：**Public Beta**（非 Stable；RQ1 formal 未取得）

## 新能力

### Java L1（默认启用，无 JVM 依赖）

- `.java` 扫描/解析/符号/引用/调用建图，复用冻结 schema 与三态引用契约
- 符号：`Class`（class/enum/record）、`Interface`（interface/annotation）、
  `Method`（method/constructor/field/enum_constant），metadata 判别符
  `java_kind` / `java_member`
- 边：`DEFINES / CONTAINS / IMPORTS / CALLS / REFERENCES / IMPLEMENTS`
- P2-A 安全收紧（R1）：receiver 类型不可知的实例调用不再产生启发式确定性
  绑定（降为 ambiguous，候选保留）——8 个历史错误绑定形态全部修复
- 225 站点新鲜分层审计：原始 L1 / 收紧 L1 / JDT / 合并后查询四模式
  **Wrong Resolution = 0**

### Optional JDT Semantic Analyzer（按需启用，query-time）

- `java-semantic` CLI + `semantic_java` capability（diagnostic 级）
- 跨文件方法精确绑定、重载消歧、继承层级、JDK 类型（21 项 gold 查询
  20+1 CORRECT；168 冲突抽样 0 JDT 错误）
- recovered（依赖缺失伪造）绑定过滤；歧义不升级为确定
- 独立 JVM 进程按需运行；provenance `semantic:jdt-v1` + classpath 指纹
- **不持久化到 L1 图谱**；默认 index 永不启动 JVM

### Classpath Manifest

手工 classpath 契约：校验/去重/顺序敏感指纹/fail-closed/BOM 兼容
（`provenlattice.classpath` 模块 + `--classpath-manifest`）。

### Driver 缓存安全修复

driver 编译缓存按 `sha256(源码 + JDT classpath)` 指纹失效——wheel 升级不再
执行旧 driver（实验确认的升级 blocker，已在 1.5.0 修复）。

## 安装

当前发布渠道为 **GitHub Release**（PyPI 发布独立决策，尚未执行）：

```bash
# 从 Release assets 安装
pip install provenlattice-1.5.0-py3-none-any.whl
# 或从源码
pip install provenlattice-1.5.0.tar.gz
```

依赖自动就位（tree-sitter 0.26 + python/c/cpp/java 语法包）。Java L1 无需 JVM。

## 可选 JDT 启用

```bash
set PL_JAVA_JDK=C:\path\to\jdk-21                      # JDK（javac+java）
set PL_JAVA_JDT_CLASSPATH=C:\jars\jdt-core.jar;...     # Eclipse JDT 及依赖（用户自备）
provenlattice java-semantic <repo> --status-only --json
provenlattice java-semantic <repo> --classpath-manifest classpath.txt --json
```

## 已知限制

- **Linux JDT：VERIFIED**（2026-10-20 更新，PR #14 CI：ubuntu-latest + Temurin 21 +
  Maven 钉扎套件，9/9 含跨平台 golden 一致；发布时 NOT_VERIFIED——详见
  docs/linux-jdt-verification-report.md；fixture 级对比，JDK 其他组合未测）
- **146 UNKNOWN**：跨文件/外部类型流站点（JDT 绑定仍提供，独立真值不可建立）
- record 组件、注解元素、匿名类体、隐式默认构造不提取
- 方法重载判定/继承绑定需启用 JDT；L1 语法层不提供
- JDT 结果为 query-time 审计视图，**不持久化到 L1 图谱**
- JDK 21（Temurin）已验证；其他 JDK 组合未测
- Maven/Gradle 永不自动执行；SCIP Java INFRA_BLOCKED（官方移除 Windows launcher）
- **RQ1 formal qualification 未取得**——Java 全部输出为工程验证
  （local-only, diagnostic）级
